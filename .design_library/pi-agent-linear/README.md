# pi-agent-linear 设计系统

**风格**: Linear/Vercel 极简精致风格

## 设计理念

- 极深暗色背景（#09090b），近乎纯黑
- 极淡边框（rgba 6% 白色），精致不突兀
- 大量留白，宽松间距
- 多层柔和阴影
- Violet 强调色（#8b5cf6）
- 统一 8px 圆角
- 精致的 hover 高亮过渡

## 色彩体系

- 背景: base → surface → elevated 三层递进
- 文本: primary → secondary → tertiary → muted 四级
- 强调色: Violet (#8b5cf6) 为主
- 语义色: 柔和版（success/warning/error/info）

## 典型卡片样式

- border-radius: 8px
- border: 1px solid rgba(255,255,255,0.06)
- background: #18181b
- shadow: 多层柔和
- header 有彩色图标容器（24x24，圆角 6px，语义色 15% 背景）
- hover 时 border 变为 rgba(255,255,255,0.1)

## 适用场景

- 追求极简精致视觉效果的 AI 编码助手
- 类似 Linear.app、Vercel Dashboard 的设计语言
