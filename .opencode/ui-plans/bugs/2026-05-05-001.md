# Bug #001

## 基本信息

- **发现时间**: 2026-05-05
- **模块**: auth/login
- **严重程度**: P1-严重
- **状态**: 已修复

## 复现步骤

1. 打开 http://localhost:5173
2. 清除 localStorage（localStorage.removeItem("rpc-auth-token")）
3. 刷新页面，进入登录页
4. 输入错误的 token（如 "wrong-token"）
5. 点击"连接"按钮

## 预期行为

- 应在超时后（如 10-15 秒）显示错误提示："连接失败，请检查 Token 是否正确"
- 提供"重试"按钮或自动回到登录页
- 不应将无效 token 保存到 localStorage

## 实际行为

- 页面一直停留在 "Connecting to RPC server..." 无限 spinner
- 无任何错误提示
- 错误 token 已被保存到 localStorage
- 用户必须手动清除 localStorage 才能恢复

## 截图/证据

- /tmp/ui-test-auth-screenshots/05-wrong-token-infinite-connecting.png

## 环境信息

- URL: http://localhost:5173
- Browser: Chromium
- AUTH_TOKEN: demo-test-token

## 建议修复方向

1. useAppStore.initializeConnection() 添加连接超时检测
2. LoginPage 组件监听连接失败状态，显示错误信息
3. 延迟写入 localStorage — 连接成功后再保存 token
4. 添加"返回登录"按钮

## 修复记录

- **修复时间**: 2026-05-06
- **修复方案**: 将超时逻辑从 LoginPage.tsx 移到 App.tsx。LoginPage 调用 onLogin() 后会被卸载，内部 setTimeout 回调无效。改为在 App 层追踪 ready 状态，15 秒未就绪则回滚 hasToken=false 并传 loginError 给 LoginPage 显示。
- **涉及文件**:
  - `src/mainview/App.tsx` — 新增 loginError 状态 + handleLogin 回调（含 15s 超时）
  - `src/mainview/components/LoginPage.tsx` — 接收 loginError/onClearError props，移除内部 loading/error/timerRef
- **验证结果**: ✅ PASS — 15秒后自动回到登录页，显示红色错误提示 + 重试按钮，localStorage 已清除
