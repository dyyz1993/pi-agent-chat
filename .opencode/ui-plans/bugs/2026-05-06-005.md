# Bug #005

## 基本信息

- **发现时间**: 2026-05-06
- **模块**: sidebar
- **严重程度**: P3-轻微
- **状态**: 已修复

## 复现步骤

1. 在桌面端浏览器（宽度 > 768px）打开 pi-agent-chat
2. 查看左侧边栏 header 区域

## 预期行为

- 应该有折叠/收起侧边栏的按钮（title="收起"）
- 桌面端用户也应该能收起侧边栏获得更多空间

## 实际行为

- 折叠按钮仅在 overlay/移动端模式渲染（`LeftSidebar.tsx:98` 中 `{overlay && ...}`）
- 桌面端侧边栏 header 只有 Sessions 计数 + New Session + Panel Pin
- 用户无法折叠侧边栏（只能通过 resize 手柄调整宽度）

## 源码参考

- 文件：`src/mainview/components/left-sidebar/LeftSidebar.tsx:98-109`
- 条件：`{overlay && (<button title={t("closePanel")}><PanelLeft/></button>)}`
- 仅当 overlay=true 时渲染

## 建议修复方向

- 考虑在桌面端也添加折叠按钮，或移除 `{overlay &&}` 条件
- 或添加键盘快捷键（如 Ctrl+B）切换侧边栏

## 修复记录

- **修复时间**: 2026-05-06
- **修复方案**:
  - 新增 use-layout-store.ts 的 sessionCollapsed 状态（持久化）
  - LeftSidebar.tsx 桌面端添加 PanelLeftClose 折叠按钮
  - ChatPanel.tsx 折叠时显示展开按钮
  - MainLayout.tsx 支持 Ctrl+B/Cmd+B 快捷键切换
- **涉及文件**: use-layout-store.ts, LeftSidebar.tsx, ChatPanel.tsx, MainLayout.tsx
- **验证结果**: ✅ PASS — 折叠后主区域从 740px→980px，Ctrl+B 恢复
