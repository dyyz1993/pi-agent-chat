# Bug #004

## 基本信息

- **发现时间**: 2026-05-06
- **模块**: theme/shortcuts
- **严重程度**: P2-一般
- **状态**: 已修复

## 复现步骤

1. 进入主界面
2. 点击左侧边栏底部的主题切换按钮，打开下拉菜单
3. 按 Escape 键

## 预期行为

- 下拉菜单关闭（与其他面板如通知中心、工作区选择器行为一致）

## 实际行为

- ESC 键无法关闭 ThemeMenu 下拉
- 必须点击外部区域才能关闭
- 通知面板和工作区选择器都支持 ESC 关闭，行为不一致

## 影响范围

- 用户体验不一致
- 违反了 ESC 关闭所有弹出层的通用交互规范

## 建议修复方向

- 在 ThemeMenu.tsx 的 useEffect 键盘监听中添加 Escape 处理
- 参考 NotificationCenter 或 Workspace 选择器的 ESC 关闭实现

## 修复记录

- **修复时间**: 2026-05-06
- **修复方案**: 在 ThemeMenu.tsx 的 handleKey 中添加 e.preventDefault() + e.stopPropagation()，确保 ESC 事件不被其他监听器截获
- **验证结果**: ✅ PASS
