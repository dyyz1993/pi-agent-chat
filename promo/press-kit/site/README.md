# Pi Agent Chat Promo Site

This is a standalone, static press site built from the local press-kit assets.

Open `index.html` directly in a browser, or serve the `promo/press-kit` directory with any static file server and visit `/site/`. For example:

```bash
python3 -m http.server 4174 --directory promo/press-kit
```

The page includes the real desktop/mobile UI recordings, reviewed screenshots, posters, and logo assets.

The site is intentionally separate from the product's Vite app so launch material can be reviewed without changing the product runtime.
