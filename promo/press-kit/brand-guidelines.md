# Brand Guidelines

## Name

Use **Pi Agent Chat** as the public name for this release pack.

Avoid mixing it with older candidate names or rejected brand explorations.

## Core Message

**Agent work should feel inspectable, steerable, and recoverable.**

Pi Agent Chat is not just another chat surface. It is an agent workbench: a place to follow what the agent did, review changes, keep goals visible, and manage local or remote project work.

## Visual System

| Token               | Hex       | Usage                                     |
| ------------------- | --------- | ----------------------------------------- |
| Graphite background | `#0E1718` | App icon background, launch material base |
| Deep panel          | `#142323` | UI panels and poster mock surfaces        |
| Border green        | `#29413F` | Icon border and subtle panel outlines     |
| Flow green          | `#35E0B4` | Primary accent and workflow line          |
| Tool blue           | `#58A6FF` | Secondary accent for tools and status     |
| Text white          | `#F5FAFA` | Primary copy                              |
| Muted text          | `#9BAEAC` | Supporting copy                           |

## Logo Usage

- Use the app icon for avatars, favicons, square social previews, and product cards.
- Use the wordmark layout in posters and README hero areas.
- Keep the icon on dark or neutral surfaces for best contrast.
- Do not place the icon on noisy screenshots without a dark backing surface.

## Screenshot Guidance

Use generated mock visuals for public launch posts unless a real screenshot has been reviewed.

Real screenshots must not expose:

- user names, home directories, API keys, or local paths
- private projects, session IDs, branch names, or unreleased task names
- real conversation content, token counts, model names, or URLs

## Tone

Clear, technical, and grounded.

Good:

- "Open-source agent workbench"
- "Follow tool activity and review agent work"
- "Desktop and web UI for coding agents"
- "Local project control"

Avoid:

- "Replaces every IDE"
- "Fully autonomous developer"
- "Guaranteed production-ready agent output"
- aggressive comparisons to specific competitors
