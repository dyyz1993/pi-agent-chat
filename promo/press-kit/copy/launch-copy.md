# Launch Copy

## English Launch Announcement

Today I am opening up **Pi Agent Chat**, an open-source desktop and web workbench for coding agents.

Most agent UIs start as a chat box. That is useful, but serious coding work needs more structure: visible tool activity, durable message history, review surfaces, goal tracking, and a way to keep local or remote project work understandable.

Pi Agent Chat is my attempt to make agent work feel like a real workspace.

It includes:

- streaming chat for coding agents
- tool and activity timelines
- review-oriented UI for generated changes
- goals and task context
- high-performance message history
- desktop and web support through Electrobun, React, Vite, and Bun
- local project workflows with room for remote runtime use cases

The project is open source under AGPL-3.0.

Repo: `https://github.com/OWNER/pi-agent-chat`

## 中文发布文案

我准备开源 **Pi Agent Chat**。

它不是一个单纯的 AI 聊天框，而是一个给编程 Agent 用的工作台：你可以看到 Agent 的工具调用、消息历史、审查流程、目标上下文，以及本地/远程项目里的执行状态。

我做它的原因很简单：Agent 真正参与开发时，最重要的不是让它“看起来很聪明”，而是让它的工作过程可见、可追踪、可回退、可继续。

它目前包含：

- 编程 Agent 的流式对话
- 工具调用和活动时间线
- 面向代码变更的审查界面
- 目标和上下文管理
- 高性能消息历史
- 桌面端和 Web 端支持
- 本地项目工作流，并为远程 runtime 留出空间

项目协议是 AGPL-3.0。

仓库：`https://github.com/OWNER/pi-agent-chat`

## README Hero Copy

**Pi Agent Chat** is an open-source agent workbench for coding, review, goals, and remote projects.

It turns agent conversations into a visible workspace: chat, tool activity, message history, review flows, and project context live together instead of being scattered across logs and terminal windows.
