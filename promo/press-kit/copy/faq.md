# Public FAQ

## What is Pi Agent Chat?

Pi Agent Chat is an open-source desktop and web workbench for coding agents. It helps developers inspect and steer agent work through chat, tool activity, review flows, goals, and project context.

## Is it an IDE?

Not exactly. It is closer to an agent workbench. It can sit beside an editor and focus on the agent workflow: conversations, tools, history, review, and project orchestration.

## Is it open source?

Yes. The current project license is AGPL-3.0.

## Does it run locally?

Yes. The project supports local development workflows and desktop/web use. Some model/provider behavior depends on how the runtime is configured.

## Does it replace Cursor, Claude Code, or other tools?

No. The better framing is that Pi Agent Chat explores a dedicated UI/workbench for coding-agent workflows. Avoid pitching it as a direct replacement for every developer tool.

## What should public screenshots show?

Use clean generated mocks or reviewed screenshots. Avoid exposing real sessions, file paths, local usernames, model usage, private project names, or unreleased work.

## What is the best one-line description?

Pi Agent Chat is an open-source agent workbench for coding, review, goals, and remote projects.
