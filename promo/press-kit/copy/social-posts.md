## 中文朋友圈 / 长一点

最近整理了一个开源项目：Pi Agent Chat。

它是给 AI 编程 Agent 用的桌面端和 Web 端工作台。相比单纯聊天框，它更强调“工作过程可见”：能看到工具调用、消息历史、代码审查、目标上下文，以及项目里的执行状态。

Agent 真正参与开发时，最怕的是过程不可见、结果不好审、上下文断掉。这个项目就是围绕这些问题做的。

项目协议是 AGPL-3.0，准备作为开源项目继续推进。
