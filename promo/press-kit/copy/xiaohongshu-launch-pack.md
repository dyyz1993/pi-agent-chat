## 首发正文

最近整理了一个开源项目：**Pi Agent Chat**。

它是一个给 AI 编程 Agent 用的桌面端 + Web 端工作台。

我不太想再做一个“只有聊天框”的 AI 工具。真正让 Agent 参与开发之后，最容易失控的其实是：

• 不知道它刚刚做了什么
• 工具调用和执行过程很难追踪
• 代码改完之后不好审查
• 上下文断掉后，很难继续工作

所以 Pi Agent Chat 把这些东西放进了同一个工作区：

• 流式 AI 对话
• 工具调用和活动时间线
• 代码变更审查
• 目标和任务上下文
• 消息历史
• 桌面端和 Web 端
• 本地项目工作流

我希望 Agent 的工作过程是可见、可追踪、可回退、可继续的，而不是只给你一个最后的答案。

项目目前还在持续迭代，欢迎开发者试用、提 Issue 或贡献代码。

🔗 GitHub：
https://github.com/dyyz1993/pi-agent-chat

## 产品能力版正文

我做的不是一个只会“回答问题”的 AI 聊天框，而是一个可以管理 Agent 工作过程的桌面端 + Web 端工作台：**Pi Agent Chat**。

它把一条完整的编程 Agent 工作流放在同一个界面里：

• 审批与权限：工具调用、文件操作和危险命令可以先询问，再执行
• 变更审查：逐文件查看新增、修改、删除的 diff，可以批准或拒绝
• 快照与回滚：Agent 执行工具后留下快照，需要时回滚，也可以取消回滚
• Git 工作区：分支、文件状态、diff、stage / unstage / commit
• Hooks 与规则：查看 Pre / Post / Stop 事件，以及 allow / block / ask 决策
• Goal 与执行记录：目标、验收条件、事件历史、暂停和继续

我更在意的不是 Agent 看起来有多“自动”，而是你始终知道它做了什么、为什么做、改了什么，以及不满意时怎么退回来。
