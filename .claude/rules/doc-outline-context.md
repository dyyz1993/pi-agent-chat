# 文档大纲上下文注入

## 规则

项目维护了一份自动生成的文档大纲，位于：

```
.pi/outlines/OUTLINE.md
```

### 所有 Agent 会话必须遵守

1. **会话启动时**：如果用户的提问涉及"文档在哪"、"项目结构"、"有哪些计划/规范"、"找文档"等，优先引用 `.pi/outlines/OUTLINE.md` 中的索引，而不是盲搜文件系统。

2. **文档引用优先级**：
   - 先查大纲索引 → 找到准确路径 → 再读取具体文档
   - 不要在大纲已有索引的情况下重复全盘扫描

3. **大纲维护责任**：
   - 大纲由 `doc-curator` agent 专门维护
   - 其他 agent **不应手动编辑** `.pi/outlines/OUTLINE.md`
   - 如果发现大纲过期，建议用户切换到 `doc-curator` 或用 `subagent` 委派刷新

4. **新增文档时**：
   - 当任何 agent 创建了新的 `.md` 文件，在回复末尾提醒：
     > 💡 新增了文档 `xxx.md`，建议运行 doc-curator 刷新大纲。

5. **需求校验入口**：
   - 大纲中的「需求文档校验」区域记录了文档与代码的一致性状态
   - 开发前先查看相关文档的校验状态，避免基于过期文档工作
