## useBookmarkStore 实现方案

### 数据结构
\`\`\`typescript
interface Bookmark {
  id: string           // UUID
  messageId: string     // 关联消息 ID
  sessionId: string     // 来源会话
  title: string         // LLM 提取标题
  summary: string       // LLM 生成的 Markdown 摘要
  tags: string[]        // LLM 提取标签
  createdAt: number
}
\`\`\`

### API
- **addBookmark(data)** — 创建（触发 LLM 总结）
- **removeBookmark(id)** — 删除
- **getBookmarks({tag?, query?})** — 过滤查询
- **isBookmarked(msgId)** — 快速检查

### 存储
写入 ~/.pi/agent/memory/ 目录，type=bookmark
Dream 不删除 bookmark，只提炼摘要。
